02 / Spatial turbidity mapping

Heat maps estimate what lies between the samples

The dashboard includes an Inverse Distance Weighting routine that estimates turbidity across a grid from readings collected at GPS locations.

How IDW works

Each nearby reading contributes to a grid estimate

For a grid location, the algorithm assigns each measured turbidity value a weight based on distance. A nearby sample receives a larger weight; a distant sample has less influence.

Data path

From a sensor point to an estimated surface

  1. 01

    Collect samples

    Record NTU turbidity readings with GPS coordinates as the boat visits waypoints.

  2. 02

    Interpolate

    For each of the 25 × 25 grid locations, combine samples using inverse-distance weights with power 3.

  3. 03

    Visualize

    Render estimated turbidity as a spatial heat map for the selected mission.

The IDW function is present in dashboard.html. Its general startup and periodic refresh calls are commented out in the supplied dashboard initialization; confirm the active view before describing it as live.

Interpretation

Estimated values are not additional measurements

A heat map is only as representative as the collected points. Sparse or uneven sampling can hide local variation, so map detail should be read alongside the boat route and original measurements.
