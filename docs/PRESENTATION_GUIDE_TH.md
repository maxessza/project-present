# คู่มือย่อการนำเสนอ Overall

## เริ่มชม
1. อ่านบทนำเพื่ออธิบายเป้าหมาย ผู้ดูแลที่สถานี และหน้าที่ของเรือ
2. กด START หนึ่งครั้งเพื่อเริ่มภารกิจจำลองชุดเดียวกัน แผนที่ การควบคุม และรายงานอ้างอิงสถานะชุดเดียว
3. ใช้ PAUSE เพื่อหยุดนาฬิกาและตำแหน่งเรือ; กด เล่นต่อ เพื่อดำเนินจากสถานะเดิม
4. เลือกฉากทั้ง 8 เพื่ออ่านคำอธิบาย การเลือกฉากไม่เริ่มใหม่หรือขยับภารกิจ; STEP ใช้ดูการเปลี่ยนสถานะทีละจังหวะ
5. กด เริ่มใหม่ เพื่อเริ่มภารกิจใหม่จากต้นทาง
6. ค่าเซ็นเซอร์และสถานะความขัดข้องที่ผู้ชมกำหนดจะคงอยู่เมื่อเริ่มใหม่ เพื่อให้ช่องควบคุมตรงกับแบบจำลอง; หากต้องการภาพมาตรฐาน ให้คืนค่าหรือเปิดสถานะเซ็นเซอร์จากส่วน “ขอบเขต / เครื่องมือทดสอบเพิ่มเติม” ก่อนกด START. ค่า 1.2V ที่ภาพยนตร์ใส่ชั่วคราวจะถูกคืนเมื่อเริ่มใหม่หรือออกจากฉากสแกน

## ขอบเขตการสาธิต
เส้นทาง ตำแหน่ง เข็มทิศ ค่าคุณภาพน้ำ การเคลื่อนที่ และการสื่อสารในหน้า Overall เป็นตัวอย่างสังเคราะห์ที่ทำงานในเบราว์เซอร์ ไม่เชื่อมต่อเรือ เซ็นเซอร์ GPS วิทยุ ESP-NOW, SD หรือระบบแผนที่จริง และไม่ใช่การยืนยันพฤติกรรมทางกายภาพหรือความปลอดภัยของเรือจริง ผลรายงานในหน่วยความจำเบราว์เซอร์ไม่รับรองการบันทึกถาวร

pH หมายถึงความเป็นกรด–ด่าง, NTU ใช้อธิบายความขุ่น และ °C คืออุณหภูมิ ตัวอย่างที่ยังวัดไม่ได้แสดงว่าไม่มีค่า ไม่ใช่ศูนย์ รายงานผูกค่ากับตำแหน่งจำลองและแยกสถานะส่งจากการได้รับยืนยันที่สถานี
