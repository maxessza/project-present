# คู่มือเว็บไซต์

## จุดประสงค์และเส้นทางเรียนรู้

เว็บนี้ใช้เล่าแนวคิดของโครงงานเรือสำรวจคุณภาพน้ำและให้ลองแบบจำลองในเบราว์เซอร์ ไม่ใช่ dashboard สำหรับควบคุมเรือจริง เปิด `index.html` แล้วจะเข้าสู่หน้า Overall เดิมทันที โดย query และ hash จะถูกส่งต่อไปด้วย ทุกหน้ามีแถบนำทาง Smart Water Boat ชุดเดียวกันซึ่งรวมเก้าปลายทาง: Overall, Waypoints, Heatmap, Sensors, Slides, Classroom, Story, Heading / PID และ Uplink

เริ่มจาก [Overall](../pages/overall.html) เพื่อเห็นภาพรวม จากนั้นใช้ลิงก์ในส่วนที่เกี่ยวข้องเพื่อเปิด [Classroom](../pages/classroom.html), [Story Lab](../pages/story.html) หรือ [Heading / PID](../pages/heading-pid.html) สำหรับการทดลองแบบละเอียด แต่ละบทเรียนมีลิงก์กลับไปยังส่วน mission readiness หรือ PID ใน Overall และ Uplink อยู่ที่ [แผง Uplink](../pages/overall.html#ms-uplink-panel)

1. [Classroom](../pages/classroom.html) สรุปการเตรียมระบบ 8 ขั้นและให้ตอบคำถามตรวจความเข้าใจ 2 ข้อ
2. [Story Lab](../pages/story.html) ทดลอง 4 ฉาก: คำสั่งถึง gate หรือไม่, เงื่อนไข readiness, การแยก permission ออกจากมอเตอร์และการเคลื่อนที่, และเส้นทางตัวอย่างไป WP1
3. [Uplink ใน Overall](../pages/overall.html#ms-uplink-panel) สร้าง snapshot ตัวอย่างเป็น packet 38 bytes, ส่ง `ArrayBuffer` ผ่าน `MessageChannel` ภายในเบราว์เซอร์ และแสดงผลฝั่งรับ พร้อมจำลอง loss, retry หรือยกเลิกการส่ง ไม่มี radio link จริง
4. [Heading / PID](../pages/heading-pid.html) เปรียบเทียบแบบจำลองสองชุดที่หันทิศไปยังเป้าหมายเดียวกัน ปรับ P/I/D และดูผลการตอบสนอง

หน้า [Overall](../pages/overall.html) เป็นบทเรียนบูรณาการ: แสดงภาพจากข้อมูลไปสู่การเดินทาง, ค่าเฉลี่ยความขุ่นจากตัวอย่าง, เส้นทางและลำดับ task, วงสแกนตัวอย่าง, การหันด้วย PID, การเตรียมเริ่มภารกิจ, การฉาย packet telemetry และแผงอธิบายการตัดสินใจ/เดินทางของเรือ เนื้อหานี้รวมทั้งภาพอธิบายและส่วนทดลองที่ขับด้วย JavaScript ในหน้าเดียว และมีลิงก์ไปยังบทเรียนแบบละเอียดโดยตรง

## แต่ละส่วนใน Overall ใช้สอนอะไร

- [LEARN](../pages/overall.html#learn) — เริ่มจากค่าตัวอย่างไปสู่ค่าเฉลี่ย เส้นทาง และการส่งต่องานระหว่าง task; ใช้ภาพ/การเลื่อนขั้นอธิบายแนวคิด ไม่ได้สร้าง FreeRTOS tasks จริงในเว็บ
- [PID](../pages/overall.html#pid) — เห็นวงจรทิศเป้าหมาย → มุมคลาดเคลื่อน → P/I/D → คำสั่งมอเตอร์ → วัด heading กลับ; เป็นภาพอธิบาย ไม่ใช่หลักฐานว่า gain พร้อมใช้กับเรือ
- [เริ่มภารกิจ](../pages/overall.html#mission-start) — ลอง readiness ของ GPS/HOME/route และส่ง START จำลอง เพื่อแยกการรับคำสั่ง การอนุญาต การสั่งมอเตอร์ และการเคลื่อนที่ออกจากกัน
- [ส่งข้อมูลกลับฝั่ง](../pages/overall.html#ms-uplink-panel) — เปลี่ยนตัวอย่างแล้วดู encode → ส่ง bytes → callback ฝั่งรับ → decode → อัปเดตจอ; packet หายทำให้ retry และลิงก์ขาดทำให้คงค่าล่าสุดพร้อม stale ไม่ใช่ภาพวนอิสระจากข้อมูล
- [OPERATE](../pages/overall.html#operate) — เล่น/เลื่อน/ย้อน checkpoint ของภารกิจจำลอง และดูเหตุผลการตัดสินใจ GRID/SPIRAL/RTH, what-if และเงื่อนไข RTH; ผลตรงนี้เป็นหลักฐานของแบบจำลองเว็บเท่านั้น

ส่วนเหล่านี้ใช้หน้ารวมเดียวกันเพื่อให้เห็นการเชื่อมกันของระบบ ส่วน Classroom, Story และ Heading แยกหน้าเพื่อให้ทดลองทีละประเด็นโดยไม่ต้องอ่านทั้งหน้า Overall

## หน้าอธิบายประกอบ

- [Waypoints](../pages/waypoints.html) อธิบายแนวกวาด 3 เส้น เส้นละ 3 จุด ลำดับสลับไปมา และแนวคิด GPS/เข็มทิศ/PID มีภาพและโค้ดตัวอย่างที่อ้างอิงเอกสารโครงงาน ตัวอย่างบนหน้ามีไว้สื่อสารแนวคิด ไม่ใช่ผลวัดความครอบคลุมภาคสนาม
- [Sensors](../pages/sensors.html) อธิบาย DS18B20, pH และ turbidity รวมถึงโมดูลสนับสนุนและความสำคัญของตำแหน่ง/สถานะเรือ เป็นเนื้อหาและภาพประกอบ ไม่มีสคริปต์ประมวลผลข้อมูลสด
- [Heatmap](../pages/heatmap.html) อธิบายแนวคิดประมาณค่าระหว่างจุดวัด มีภาพขั้นตอนการเก็บตัวอย่างและการประมาณค่า แต่หน้านี้ไม่มี JavaScript สร้างกริด ไม่มี backend และไม่มีชุดข้อมูลภาคสนาม
- [Slides](../pages/slides.html) สร้างชุดสไลด์จากข้อมูลในไฟล์ JavaScript และภาพประกอบที่เก็บในโครงการ

หน้า Waypoints, Sensors และ Heatmap เป็นหน้าเนื้อหาเชิงอธิบายและอาจผสมแผนภาพกับ snippet ที่ยกมาเพื่อเล่าโครงงาน การมี snippet หรือชื่อส่วนประกอบในข้อความไม่ได้แปลว่ามีระบบนั้นทำงานอยู่ในเว็บไซต์นี้

## ตัวอย่างในเว็บกับระบบจริง

Classroom, Story, Heading/PID และ Uplink ขับด้วยแบบจำลองฝั่งเบราว์เซอร์ คำว่า “ส่ง” หรือ “เรือ” ในการทดลองหมายถึงการเปลี่ยนสถานะหรือแสดง packet จำลอง ไม่มีการส่งวิทยุ ไม่มีเรือเชื่อมต่อ และไม่มี hardware telemetry จริง ภาพการต่อวงจรและภาพโครงสร้างเรือเป็นภาพประกอบ ไม่ใช่การตรวจยืนยันว่าอุปกรณ์พร้อมใช้งาน

ไฟล์ [SPEAKER_NOTES.md](SPEAKER_NOTES.md) เป็นบันทึกผู้บรรยายของสไลด์เดิม เก็บเป็นเอกสารประวัติ เนื้อหานั้นไม่ใช่คำอธิบายสถาปัตยกรรมที่ยืนยันจาก source ปัจจุบัน
