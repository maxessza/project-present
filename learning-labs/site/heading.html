แบบจำลองนี้ต่างจากเรือจริงอย่างไร?

ลูกศรหมุนอยู่กับที่ ไม่ได้จำลองเส้นทางหรือมอเตอร์จริง ค่า gains และ preset ใช้สอนกับระบบตัวอย่างนี้เท่านั้น D ไม่ได้ทำให้ทุกระบบดีขึ้นเสมอ

โมเดล: yaw acceleration = u + disturbance − 0.45 × yaw rate; heading เพิ่มตาม yaw rate. ใช้ dt 0.05 s, จำกัด u ±60 หน่วยจำลอง, derivative filter α=0.25 และหยุดสะสม I เมื่อการสะสมจะดัน output ที่อิ่มตัวออกไปอีก

อิงแนวคิดจาก HeadingController / PidController: angular error, PID, output saturation. ไม่ได้พอร์ต controller ทั้งตัว และโหมด GRID ใช้ PI ร่วม heading-rate damping ไม่ใช่ PID แบบเดียวกันทุกโหมด

แบบจำลองเพื่อเรียนรู้ ไม่ใช่ค่าจูนเรือจริง / ไม่เชื่อมต่อเรือไม่มี GPS / PWM / telemetry สด · software demonstration only
